# Distributed Search Engine in Java

A production-inspired distributed search engine built in Java featuring sharding,
parallel query execution, inverted indexing, and fault-tolerant system design.

---

## 🚀 Motivation
Modern search engines rely on distributed architectures to handle massive
datasets with low latency. This project focuses on understanding and
implementing the core building blocks of such systems from scratch.

---

## 🧠 Core Features
- Distributed inverted index
- Sharded search nodes
- Parallel query execution
- Central query coordinator
- Ranking and result aggregation
- Fault tolerance with timeouts

---

## 🛠 Tech Stack
- Java 17
- Spring Boot
- REST APIs
- Java Concurrency
